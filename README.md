## 📌 Overview

The **Sensor Fault Detection** project is an end-to-end Machine Learning pipeline designed to detect anomalous or faulty sensor readings in real-time. By leveraging robust data preprocessing, automated model training, Docker containerization, and AWS CI/CD deployment, this system ensures reliable predictive maintenance for industrial sensors.

---

## 🎯 Key Features

- <span style="color:#0066CC"><b>Automated Data Pipeline:</b></span> Automated ingestion, validation, and preprocessing routines.
- <span style="color:#0066CC"><b>Machine Learning Models:</b></span> Advanced classification algorithms tuned to identify subtle sensor anomalies.
- <span style="color:#0066CC"><b>Containerized Deployment:</b></span> Dockerized setup ensuring environment consistency across development and production.
- <span style="color:#0066CC"><b>AWS Integration:</b></span> Configured for seamless deployment on AWS EC2 with S3 integration for artifact storage.
- <span style="color:#0066CC"><b>Continuous Integration & Deployment:</b></span> GitHub Actions workflows for automated testing and deployment.
